# 圣经生命读经 · 阅读器 — 产品设计文档

## 产品概述

一款专注于圣经生命读经（Life Study of the Bible）阅读的跨平台 App，收录全部 66 卷圣经的生命读经文章（2,058 篇）。架构继承自倪柝声文集阅读器。

**平台**: H5 / Android / iOS  
**技术**: React + Capacitor 跨平台方案

## 用户画像

- 对圣经生命读经有深度阅读需求的基督徒
- 需要按书卷快速定位文章
- 希望追踪阅读进度，长期持续阅读
- 偏好简洁、无干扰的阅读界面

## 信息架构

```
首页（圣经）
├── 新约 / 旧约 Tab 切换
├── 按分类展示书卷网格（4 列）
│   ├── 摩西五经 (5 卷)
│   ├── 历史书 (12 卷)
│   ├── 诗歌智慧书 (5 卷)
│   ├── 先知书 (17 卷)
│   ├── 福音书 (4 卷)
│   ├── 教会历史 (1 卷)
│   ├── 保罗书信 (14 卷)
│   ├── 普通书信 (7 卷)
│   └── 预言书 (1 卷)
└── 继续阅读卡片

搜索
└── 全文搜索 → 关键词高亮 → ?from=search 跳转阅读

我的
├── 阅读统计（4 卡片）
├── 阅读历史（按日分组）
└── 阅读设置（主题 / 字号）
```

## 页面设计

### 首页

- 顶部标题「圣经生命读经」
- 新约/旧约 Tab 切换
- 按分类分组，每分类下 4 列书卷卡片
- 书卷卡片：简称（大字）+ 全名 + 文章数
- 继续阅读：绿色背景卡片，点击续读

### 文章列表

- 顶部：返回 + 书名
- 文章列表：序号 + 标题
- 点击进入阅读器

### 阅读器

- 全屏沉浸，隐藏底部 Tab
- 点击屏幕切换控制栏
- 顶部栏：返回 + 书名 + 文章进度
- 底部栏：主题 + 字号 + 目录
- 右侧滚动进度指示器
- 文末上一篇/下一篇导航
- 计时器（页面可见时计时，后台暂停）

### 搜索

- 全文章标题和内容搜索
- 关键词高亮
- 搜索结果显示所属书卷名
- 搜索跳转不计入阅读进度和历史

### 我的

- 4 格统计：累计阅读、已读文章、连续天数、今日阅读
- 阅读历史：最近 50 条按日期分组
- 设置：主题三选一 + 字号四选一
